# Ember Coffee

Ember Coffee is a Web Fundamentals project for a fictional coffee shop. The responsive website presents the café, its menu, photo gallery, and visitor information.

## Features

- Interactive menu with search suggestions, sorting, and filters for cold drinks, decaf, and plant-based milk options.
- Five main pages covering the home page, menu, café story, visitor information, and gallery.
- Weather-based drink recommendations on the home page.

## Technologies

HTML, CSS, JavaScript, jQuery, and Bootstrap.
